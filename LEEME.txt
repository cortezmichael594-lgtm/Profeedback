CARPETA «addons»: taller de complementos de Anki

Qué es: una carpeta de trabajo para que Claude Code cree y mantenga sus complementos de Anki.
Usted le dice en lenguaje normal lo que quiere; él lo construye, lo comprueba y le deja un
archivo .ankiaddon listo para instalar con doble clic.

Puesta en marcha (una sola vez):
  1. Abra Claude Code en esta carpeta (en la aplicación de escritorio: pestaña «Code», entorno
     «Local» y esta carpeta como carpeta del proyecto).
  2. Escriba: Prepara el entorno
     Claude Code le pedirá permiso para instalar unas piezas dentro de esta carpeta. Responda que sí.
  3. A partir de ahí, pídale lo que quiera. Ejemplos:
       «Crea un complemento que me avise de las tarjetas con muchos fallos.»
       «Corrige el complemento X: el botón parpadea al abrir la ventana.»

Qué hay en cada carpeta:
  CLAUDE.md        las instrucciones que Claude Code lee solo al empezar. No hace falta tocarlo.
  docs/            documentos de consulta (su paleta Nocturne, la guía de Anki y una guía de interfaz),
                   lo que Claude Code aprende de una sesión a otra y, por cada complemento, qué hace
                   y sus errores.
  complementos/    aquí van los complementos. Para mejorar uno que ya tiene, copie su carpeta aquí
                   (en Anki: Herramientas > Complementos > seleccionar > Ver archivos).
                   Si está vacía, Claude Code entenderá que quiere uno nuevo.
  pruebas/         pruebas automáticas de cada complemento (las escribe Claude Code).
  herramientas/    el comprobador y empaquetador (lo usa Claude Code) y, en copias/, una copia de las
                   instrucciones de antes de cada cambio que usted apruebe.
  paquetes/        aquí aparecerán los .ankiaddon terminados (se crea sola).

Su colección de Anki no está en esta carpeta y Claude Code tiene prohibido leerla o tocarla.
